04 · Core algorithm

Graph Search ไม่ได้ค้นแค่คำเหมือน
แต่เดินตาม เส้นทางความสัมพันธ์

Execution flow

01 · Seed
Query → entity / triple seedsหา anchor ที่อยู่ในคำถาม
02 · Walk
Personalized PageRankกระจายน้ำหนักบน Graph ที่เกี่ยวข้อง
03 · Bridge
Entity → Chunk projectionแปลงผล Graph กลับเป็น evidence ที่อ่านได้
04 · Trace
เก็บ seed, candidates, rankingตรวจสอบได้ว่าได้หลักฐานมาอย่างไร

11 · Takeaway

จากคำถาม
สู่หลักฐานที่ ตรวจสอบได้

SemiGraph แสดงให้เห็นว่า Graph Retrieval และ Structured Financial Retrieval เติมช่องว่างของ Vector RAG ได้ในโดเมน Semiconductor

งานที่เหลือคือทำให้ระบบ Production เร็วขึ้น และวัด Full Agent ให้ครบ ไม่ใช่เริ่มสร้างแกนระบบใหม่
Backend algorithm scope: ready for defense

Final message
