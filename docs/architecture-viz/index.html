Design note

เส้นทึบคือ runtime path, เส้นประคือ optional / retry / data preparation

01

Agent ไม่ได้ค้นครั้งเดียวแล้วตอบ

มันแยก evidence requirements, ประเมิน chunk ที่ได้ และอนุญาต retry เฉพาะการเปลี่ยน query/tool ที่มีสาระและยังอยู่ในงบ

02

Graph กับ Vector ใช้ข้อมูล SEC ชุดเดียวกัน

ต่างกันที่ index และกลไกจัดอันดับ: Vector ใช้ cosine บน Chunk ส่วน Graph ใช้ triple seeds + PPR บน Entity–Chunk topology

03

Financial แยก numerical truth ออกจาก narrative

ตัวเลขผ่าน validated intent และ allowlisted SQL template ไปยัง PostgreSQL; ไม่มี LLM-generated SQL และ provenance ติดมากับทุก row
