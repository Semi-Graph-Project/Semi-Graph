# Use two-pass shared answer generation

Full-answer evaluation uses one shared two-pass generator for Vanilla Vector, Graph, Agent Vector, and Agent Graph. The first pass keeps `HUMAN_REVIEW_SYNTHESIS_PROMPT` unchanged; the second pass rereads the Original Query, every retrieved Chunk, and the Draft Answer to fill supported omissions and correct factual or calculation errors. This deliberately adds one LLM call per answered Query in exchange for better Question Point coverage, while keeping the comparison fair because neither pass receives PlanRoute output, Gold Answer Points, or outside knowledge. If the audit fails, the valid Draft Answer is retained; if neither answer has the required format, the system returns an explicit generation-error message instead of an empty answer.
