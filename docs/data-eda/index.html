04 · INTERPRETATION

Method, sources, and limits

Use these boundaries when presenting the EDA. The three layers answer different questions and should not be merged into one “dataset size.”

Master dataset

What was supplied by FinReflectKG.

The 555 records contain generated questions, answers, declared paths, and copied evidence chunks across 68 tickers. They describe the source QA dataset, not the production corpus.

SOX74 Gold subset

What retrieval is expected to recover.

The subset keeps 74 semiconductor questions with exact source questions and answers. Gold matching uses Chunk IDs, so alternative valid evidence may not receive credit.

Controlled graph

What the retrievers can actually search.

The database contains all 82 unique Gold chunks plus 820 uniformly sampled Non-Gold chunks. All four retrieval configurations must use this same snapshot for a fair comparison.

Key limitations visible in the data

Graph-oriented Gold construction

81/82 Gold chunks have extracted triples, compared with 312/820 Distractors. This is expected from path-based question creation, but it favors evaluation of graph-retrievable evidence.

Random is not necessarily hard

Distractors were sampled uniformly, not selected for semantic similarity. The benchmark may contain easier negatives than production search.

Repeated evidence

Multiple questions reuse the same Gold chunks, so per-query scores are not evidence-level independent.

Controlled scale

902 chunks support a controlled architecture comparison, but do not measure retrieval at full-corpus production scale.
